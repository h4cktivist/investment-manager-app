# Investment Manager

Учёт инвестиций в инструменты российского фондового рынка: сделки и выплаты,
календарь купонов и дивидендов, метрики доходности и риска, облигационные
расчёты и сравнение с индексами Мосбиржи.

Данные о рынке берутся из **MOEX ISS API** — публичного и бесплатного.

```
investment-manager/
├── backend/     FastAPI + SQLAlchemy 2 + Alembic + PostgreSQL
├── frontend/    React 18 + TypeScript + Vite + TanStack Query + Recharts
└── docker-compose.yml
```

---

## Быстрый старт

```bash
cp .env.example .env
docker compose up -d --build      # поднимет PostgreSQL и бэкенд на :8000

cd frontend
npm install
npm run dev                       # фронтенд на :5173
```

Открыть <http://localhost:5173>. Документация API — <http://localhost:8000/api/docs>.

API отвечает сразу после миграций; история индексов-бенчмарков с 2013 года
догружается фоновой задачей (полторы-две минуты при первом запуске). Дальше:

1. Создать портфель и завести операции на странице **Сделки** — инструмент
   ищется прямо на Мосбирже по тикеру или названию.
2. История цен и купонные графики по вашим бумагам догрузятся в фоне (1–3 минуты).
3. Дашборд наполнится данными.

## Функциональность

| Раздел | Что делает |
|---|---|
| **Дашборд** | Стоимость портфеля во времени, структура по классам активов, пассивный доход, доходность против индексов, полученные выплаты по месяцам, ближайшие выплаты, ключевые метрики, топ позиций |
| **Пассивный доход** | Сколько портфель принесёт деньгами за ближайшие 12 месяцев: сумма, средний платёж в месяц, доходность к рыночной стоимости и к вложенной сумме, разбивка на купоны и дивиденды, помесячный прогноз и вклад каждой бумаги |
| **Позиции** | Открытые и закрытые позиции: количество, средняя цена, рыночная цена, бумажная и реализованная прибыль, полученные выплаты, изменение за день. Цены обновляются вживую по WebSocket |
| **Сделки** | Добавление, правка и удаление операций: покупка, продажа, дивиденд, купон, амортизация, сплит, пополнение, вывод, налог, комиссия, проценты. Тикер ищется прямо на Мосбирже |
| **Календарь** | Ожидаемые купоны, амортизации, погашения и дивиденды по текущим позициям на горизонте до двух лет + история фактически полученных выплат |
| **Облигации** | По каждому выпуску: текущая доходность, простая к погашению, эффективная, дюрация Маколея и модифицированная, НКД, срок до погашения. Плюс средневзвешенные показатели по всему облигационному портфелю |
| **Метрики** | TWR, XIRR, волатильность, максимальная просадка, бета, альфа, корреляция, коэффициенты Шарпа и Сортино — на семи горизонтах сразу |
| **Бенчмарки** | Сравнение с IMOEX, MCFTR, RGBITR, RUCBTRNS, RUGBITR10Y |
| **Активы** | Справочник инструментов, ручная синхронизация с биржей, создание кастомных активов (вклад, накопительный счёт) |

## Как считаются метрики

Ключевые соглашения — они определяют, что именно вы видите на экране.

### Денежный остаток и внешние потоки

Операции пополнения счёта заводят далеко не всегда. Без них денежный остаток ушёл
бы в минус, а TWR и XIRR посчитать было бы невозможно. Поэтому если на покупку не
хватает денег, недостающая сумма записывается как **внешнее пополнение в дату
сделки**. Явные операции `Пополнение` / `Вывод`, если вы их заводите, учитываются
как есть и не дублируются.

### TWR — доходность, очищенная от вводов и выводов

Дневная доходность считается как `r = V_t / (V_{t−1} + F_t) − 1`, где `F_t` —
внешний поток дня; потоки считаются пришедшими в начале дня. Дни цепляются
произведением. Для периода, начинающегося не с нуля, базой служит стоимость
портфеля на **предыдущий торговый день** — иначе месячная доходность считалась бы
от случайного платежа внутри окна.

Доходности считаются только по **торговым дням Мосбиржи**; потоки выходных
переносятся на ближайший торговый день. По календарным дням волатильность была бы
занижена нулевыми выходными.

К году доходность приводится только на окне от 30 дней — на более коротких
интервалах возведение в степень `1/years` превращает шум в тысячи процентов.

### XIRR — денежно-взвешенная доходность

Внутренняя норма доходности по датированным потокам: пополнения со знаком минус,
выводы и итоговая стоимость — со знаком плюс. Если период начинается не с нуля,
стоимость на его начало входит в поток как первоначальное вложение. Решается
методом Ньютона с запасной бисекцией.

TWR и XIRR почти всегда расходятся, и это нормально: TWR отвечает на вопрос
«как сработала стратегия», XIRR — «сколько заработали мои деньги с учётом того,
когда я их вносил». В шапке дашборда как основная цифра доходности показан
**XIRR** — он уже годовой и ближе к бытовому «сколько процентов я заработал»;
TWR остаётся рядом справочно и используется в сравнении с индексами, где важна
именно очищенная от пополнений динамика.

### Пассивный доход

Ожидаемые купоны и дивиденды по текущим позициям на 12 месяцев вперёд, из того
же календаря выплат. **Амортизация и погашение в доход не входят** — это возврат
тела долга; они показаны отдельной строкой, иначе доходность выглядела бы кратно
выше реальной.

По облигациям учитывается весь известный купонный график; у флоатеров
необъявленные купоны прогнозируются по последнему известному значению, и доля
таких прогнозов выводится рядом. По акциям учитываются **только уже объявленные**
дивиденды — ISS не знает о невыплаченных решениях, поэтому дивидендная часть
занижена. Налог не вычитается.

Доходность считается двумя способами: к текущей рыночной стоимости позиций
(«сколько процентов от сегодняшней цены портфеля вернётся деньгами») и к
себестоимости.

### Риск

* **Волатильность** — стандартное отклонение дневных доходностей × √252.
* **Максимальная просадка** — по накопленному индексу TWR, а не по стоимости
  портфеля: иначе пополнение счёта выглядело бы как рост, а вывод — как просадка.
* **Бета и альфа** — регрессия дневных доходностей портфеля на доходности индекса.
* **Шарп** = (годовой TWR − безрисковая ставка) ÷ волатильность.
* **Сортино** — то же, но в знаменателе только просадочная волатильность
  относительно безрисковой ставки.

Безрисковая ставка задаётся в `.env` (`RISK_FREE_RATE`, по умолчанию 16 % годовых)
и меняется прямо на странице «Метрики». При высокой ключевой ставке отрицательный
Шарп означает лишь, что портфель отстал от депозита.

### Себестоимость и прибыль

Списание при продаже — **FIFO**. Комиссия и уплаченный НКД входят в себестоимость
лота. Амортизация номинала уменьшает себестоимость пропорционально и не считается
доходом от переоценки. Сплит умножает количество и делит цену.

### Облигации

Все доходности считаются от **грязной цены** (чистая + НКД) по полному графику
купонов, амортизаций и погашения из ISS.

* **Текущая доходность** — купоны за ближайшие 12 месяцев ÷ чистая цена.
* **Простая к погашению** — `(весь будущий поток − грязная цена) / грязная цена × 365/дней`.
* **Эффективная** — ставка, при которой дисконтированный поток равен грязной цене
  (то же, что Мосбиржа показывает как «доходность»).
* **Дюрация Маколея** — средневзвешенный срок возврата денег; модифицированная —
  Маколея ÷ (1 + доходность).

У флоатеров будущие купоны ещё не объявлены — они прогнозируются по последнему
известному значению, такие выпуски помечены как «оценка».

Котировки облигаций на бирже даны в процентах от номинала; внутри приложения они
переводятся в рубли с учётом уже прошедших амортизаций.

## Про «риалтайм» цен

Честная картина по бесплатным источникам:

| Провайдер | Задержка | Что нужно |
|---|---|---|
| **MOEX ISS** (по умолчанию) | ~15 минут | ничего, публичный API |
| **T-Invest API** | без задержки | бесплатный токен, выдаётся при наличии счёта в Т-Инвестициях |

Бэкенд опрашивает выбранного провайдера каждые `QUOTE_POLL_SECONDS` секунд,
складывает котировки в базу и рассылает изменения фронтенду по WebSocket
`/ws/quotes` — интерфейс обновляет цены без перезагрузки страницы. Индикатор
«онлайн» в шапке показывает состояние сокета.

Переключение на T-Invest:

```bash
# .env
QUOTE_PROVIDER=tinvest
TINVEST_TOKEN=<ваш токен>
```

Данных без задержки и без регистрации Мосбиржа не отдаёт никому — это ограничение
биржи, а не приложения.

## Кастомные активы

Для банковского вклада: **Активы → + Кастомный актив**, цена единицы `1`, ставка и
периодичность выплат. Затем **Сделки → Добавить → Покупка** этого актива, где
количество равно сумме вклада в рублях. Календарь ожидаемых выплат построится по
ставке автоматически; при включённой капитализации проценты вместо выплат
увеличивают стоимость актива.

## Разработка

```bash
# тесты расчётного ядра
docker compose exec backend python -m pytest tests/ -q

# новая миграция после правки моделей
docker compose exec backend alembic revision --autogenerate -m "описание"
docker compose exec backend alembic upgrade head

# фронтенд
cd frontend
npm run typecheck
npm run build
```

Ручное обновление рыночных данных: кнопка «Обновить всё с биржи» на странице
«Активы» или `POST /api/sync`.

### Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `POSTGRES_PORT` | `5433` | внешний порт БД |
| `BACKEND_PORT` | `8000` | порт API |
| `QUOTE_PROVIDER` | `moex` | `moex` или `tinvest` |
| `QUOTE_POLL_SECONDS` | `15` | период опроса котировок |
| `TINVEST_TOKEN` | — | токен T-Invest API |
| `RISK_FREE_RATE` | `0.16` | безрисковая ставка для Шарпа и Сортино |
| `SYNC_ON_STARTUP` | `true` | догружать историю индексов фоном при старте |

## Ограничения

* Мультивалютность заложена в схеме, но переоценка ведётся в рублях —
  для инструментов в валюте курсовая переоценка не считается.
* Дата выплаты дивиденда оценивается как «отсечка + 10 дней»: ISS отдаёт только
  дату закрытия реестра.
* Простая доходность к погашению занижена для амортизируемых выпусков — она делит
  весь поток на полный срок до погашения. Для них ориентируйтесь на эффективную.
* Налог на дивиденды и купоны учитывается, только если он указан в операции;
  автоматического расчёта НДФЛ нет.
